# 餐厅自助点餐系统

这是一个基于Java和SQL语言、在BS架构模式下运行以及应用SSH开发框架和数据库技术实现的Web应用系统，主要包括如下4个功能模块：

* 1\. 浏览查阅模块：

该系统模块描述了未注册访客端的功能，具有搜索菜品、查看菜品分类、查看菜品具体信息、登录/注册功能。

* 2\. 顾客点餐模块：

该系统模块描述了注册顾客端特有功能，具有选定菜品、查看点餐列表、结账付款、积分优惠、查看与修改个人信息功能。

* 3\. 餐厅服务员模块：

该系统模块描述了餐厅服务员端特有功能，具有添加/删除/修改菜品信息、查看订单信息、修改订单属性（是/否已上菜、确认订单等属性）、查看与修改个人信息功能。

* 4\. 系统管理员模块：

该系统模块描述了系统管理员端的功能，具有具有添加/删除/修改菜品信息、查看订单信息、修改订单属性（是/否已上菜、确认订单等属性）、查看与修改个人信息、对用户信息进行增删改查功能。



**本项目只是初学者的一次简单尝试，有待完善。**
